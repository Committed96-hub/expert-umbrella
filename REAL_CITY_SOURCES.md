## Работающие DEMO-сценарии

- «Нейва» → сведения о реальном фильме «Вышка 2» → отдельные учебные даты и сеансы → DEMO-зал → выбор до 6 мест → учебная сумма → корзина билетов → серверный DEMO-билет → скачивание. Билет не действителен для прохода. Реальных мест, бронирований и оплаты нет.
- Solo → отдельная «Учебная кухня · сценарий Solo» → DEMO-категория → тестовое блюдо → количество → существующая корзина → доставка/самовывоз → серверный пересчёт → demo-заказ. Это не официальное меню или цены Solo. Ресторан не получает заказ.
- Работа → подробности публикации → тестовое сообщение → demo-отклик без отправки работодателю.
- Биржа → DEMO-заявка на установку смесителя → сравнение трёх вымышленных предложений → выбор → учебный чат с demo-ботом → завершение без платежей → новая заявка.
- Автомобили → характеристики → избранное → сравнение с явно архивным примером → переход к исходной карточке.
- ТЦ → проверяемые магазины → раскрытие карточек → переход к официальному каталогу товаров без вымышленных остатков, цен и акций.
- Медицина → контакты реальной поликлиники → официальный сайт записи; отдельная прежняя demo-запись к специалисту. Свободные медицинские талоны не выдумываются.
- Парки и город онлайн → сведения, источник/исторический снимок, сохранение места. Прямой эфир не имитируется.

## Что требует подключения и не считается выполненным

- Права и оригинальные фотографии «Нейвы», Solo (фасад, интерьер, блюда), ТЦ, магазинов, товаров, автомобиля и парка. Это препятствует полной фотографической приёмке всех разделов.
- Текущие реальные киносеансы, схема зала, цены и афиши с правами: официальный API/партнёрская интеграция киноцентра.
- Официальное меню Solo, цены и условия доставки: разрешённый API/фид или предоставленный заведением каталог.
- Актуальность вакансии: источник содержит публикацию от 23.09.2026; открытость на момент посещения необходимо проверить. Для авто есть публикация от 01.10.2026; фактическое состояние товара и его наличие проверяются у продавца.
- ТЦ «Комсомол» не идентифицирован отдельно. Проверенный источник называет «Комсомолец»; соответствие названий не предполагается.
- Актуальные остатки магазинов, местные цены, акции: официальные фиды/разрешённые API сетей.
- Автоматические вакансии: официальный API «Работа России» или согласованный API платформы работодателей.
- Транспорт: подтверждён маршрут № 4 по публикации марта 2026, без расписания и реальных прогнозов прибытия. Нужен официальный актуальный фид муниципалитета/перевозчика (GTFS/GTFS-RT при наличии).
- Разрешённые видеопотоки и согласование точек камер с операторами.
- Медицинские талоны: согласованная интеграция с учреждением/ФМБА/региональным сервисом.
- Аптеки: легальная интеграция лицензированных сетей; наличие и продажи в приложении отключены.
- PostgreSQL и объектное хранилище для постоянного production-хранения: нынешний SQLite на Vercel временный, история demo может исчезнуть при смене инстанса.
- Платёжный провайдер, авторизация и финансовые действия в этом этапе не подключались.

## Ограничения среды

Сетевой доступ к Wikimedia и городским доменам в shell по-прежнему ограничен. По согласованию пользователя работа продолжается с доступными проверками. Функциональные браузерные тесты намеренно блокируют внешние фотографии и проверяют UI/сценарии; они не доказывают загрузку оригиналов. Локальная сборка и сценарии проверены отдельно от Vercel. Соединение Vercel ранее возвращало 403 для чтения защищённого Preview и логов; проверка READY не равна удалённой проверке приложения. Production не публикуется.

## Проверки этого этапа

- Production build Vite + TypeScript успешно проходит.
- 15 серверных и модульных тестов: пересчёт сумм, идемпотентность, запрет недоступных/повторных мест, изоляция сессий и корректность переходов заказа.
- Полный новый пользовательский путь и прежний коммерческий путь прошли на 320, 390 и 1440 px. Новый путь отдельно выполнен на локальной production-сборке.
- Проверены все основные маршруты, поиск, пустые результаты, раскрытие карточек, формы, избранное, сравнение, корзина, темы и отсутствие горизонтального переполнения страницы.
- Проверены loading/error/retry существующего API.
- Axe: 22 маршрута обеих тем без найденных нарушений WCAG 2 A/AA и 2.1 AA; отдельно проверено состояние выбора места в зале в обеих темах.
- Фотографии намеренно исключены из функционального теста из-за сетевого запрета; это ограничение не скрывается и не считается успешной проверкой загрузки.
