# Проверка версии 0.2

12 октября 2026 года. Проверена production-сборка существующего репозитория.

- `npm run build`: TypeScript и Vite проходят, JS около 277 kB / 85 kB gzip; CSS около 19 kB / 5 kB gzip. Зависимости браузерных тестов не входят в клиентскую сборку.
- `npm test`: 6 успешных проверок поиска, маршрутов, demo-происхождения, отмены запроса, замены источника и демопомощника.
- Chromium, 1440×1000, 390×844, 320×740: все 11 маршрутов; карточки, категории, даты, доступность медицинских окон, глобальный и адресный поиск, пустые результаты и сброс, избранное после перезагрузки, создание объявления, комментарии и помощник проходят.
- Отдельная инъекция сбоя источника только в тестовом браузере: состояние загрузки, ошибка и успешный повторный запрос проходят.
- В этих сценариях нет JS-ошибок, HTTP-ошибок ресурсов и горизонтального переполнения; пустых/заглушечных ссылок нет.
- axe-core WCAG A/AA: 0 обнаруженных нарушений на пяти экранах (лента, медицина, события, поиск, помощник), на мобильном и desktop.
- Локальное появление карточек: примерно 0,26–0,42 секунды. Это локальная проверка, не измерение реальной сети, Lighthouse/Core Web Vitals или полный аудит доступности.
- Проверены скриншоты мобильного экрана. Safari/iOS и реальные устройства не проверялись.

## Повторение браузерных проверок

```bash
npm ci
npm run build
npx playwright install chromium
npm run preview -- --port 4180
```

В другом терминале:

```bash
npm run test:browser
QA_WIDTH=1440 node tests/accessibility.cjs
```

Для существующего системного Chromium: `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`. Адрес сервера можно задать через `BASE_URL`.

## Источники и публикация

Все каталоги и городские сервисы используют demo-данные. Локальные объявления и комментарии создаются пользователем в браузере. Реальные медицинские записи и транзакции недоступны.

Vercel обнаружил два проекта, связанных с репозиторием, но запрос списка деплоев получил 403 (нет доступа к командной области). Собственной авторизации Vercel CLI в окружении нет. Статус нового production deployment не подтверждён; commit/push и статус GitHub фиксируются отдельно после отправки изменений.

## Проверка midnight-редизайна

12 октября 2026 года:

- Светлый stylesheet заменён целиком; новый body `rgb(8, 15, 29)`, навигация и карточки navy. Полноэкранная панорама, hero-поиск и подборки реализованы отдельными компонентами.
- Production build и 6 unit-тестов проходят. Клиентский JS около 285 kB / 87 kB gzip, CSS около 33 kB / 8 kB gzip; два локальных иллюстративных PNG суммарно около 4,4 MB.
- Существующие браузерные сценарии, включая объявления, комментарии, избранное, городской поиск, фильтры, карточки, demo-помощника и ошибки источника, прошли после редизайна на 320, 390 и 1440 px.
- `test:midnight`: тёмные поверхности, 7 быстрых входов, 8 подборок, 5 мобильных пунктов, hero-поиск и отсутствие переполнения проходят на всех трёх ширинах.
- Визуально просмотрены Chromium-скриншоты главной, подборок, мастеров и медицинского раздела. Новый midnight-интерфейс реально отображается. Скриншоты сняты после завершения анимаций.
- axe WCAG A/AA на пяти проверенных экранах, mobile и desktop: 0 найденных нарушений. Аудит ожидает завершения умеренной анимации появления; `prefers-reduced-motion` отключает её.
- На 320 px длинная подсказка поиска вынесена в переносимую подпись; горизонтального переполнения страницы нет. Карусели имеют собственную горизонтальную прокрутку.
- Реальные устройства/iOS Safari и аудит удалённого production URL не проверялись. Результат автодеплоя проверяется через GitHub status после push.

## Этап API, Биржи, кафе, корзины и бонусов

- Каталоги/городские seeds перенесены в `server/seed`; клиентская сборка не содержит seed-описаний меню, кафе и расписания.
- Проверены frontend и backend TypeScript, production build, 12 unit/server-тестов: цена рассчитывается сервером, лимит баллов соблюдается, невалидный заказ не меняет баланс, повтор заказа idempotent, баланс/истории изолированы по demo-сессиям.
- Chromium 320/390/1440: город/погода/время → объявление через API с reload → Биржа/отклик → услуга/demo-запись → кафе/меню → корзина → demo-баллы → demo-заказ → история начисления/списания с reload → будущая аптека. Все сценарии прошли; деньги не списываются.
- Прежние сценарии поиска, фильтров, карточек, объявлений, комментариев, избранного и помощника сохранены. HTTP loading/error/retry проверяется подменой ответа API только в тестовом браузере.
- Origin-защита: допустимый POST через Vite 201; POST с чужим Origin 403. Прокси сохраняет Host, чтобы не ломать легальные формы.
- Реальны только часы Урала и работа локального API/SQLite; контент, меню, погода, задания, записи, заказы и баллы demo. Аптечные офферы не имитируются.
- Vercel `/tmp`-хранилище временное. Production persistence и реальные финансовые/аптечные/медицинские интеграции не проверены и не включены.
